Set up Modmail

You need a Discord account, a bot application you own, and an available OffsetTech hosting slot.

1. Prepare your Discord bot

In the Discord Developer Portal, create a bot application. On its Bot page, enable Server Members Intent and Message Content Intent. Invite that bot to your server with permission to view channels, send messages, attach files, manage channels and read message history.

2. Deploy from your dashboard

Sign in with Discord, choose Add bot, and enter a name, your Discord server ID and your bot token. Only applications owned by your Discord account can be deployed. Keep the token private.

3. Finish server setup

Wait for the bot to connect, then run ?setup in your server. Use ?permissions to configure staff access. DM the bot to test a ticket.

Manage your instance

Use Start, Stop and Restart from the dashboard. These actions are queued by the hosting platform. Edit can change the display name, server ID or rotate the token for the same application. Delete removes the instance; retained database volumes require operator recovery and are not an automatic restore feature.

Discord commands

Install OffsetTech's commands in your server after the integration has been configured by the owner. Use /status, /start bot, /stop bot and /restart bot with your exact bot name or dashboard ID. /deploy, /edit, /delete and /billing open the private website. Replies are private.

Hosting limits

One bot uses one slot. Staff may revoke hosting; revoked bots cannot be restarted by customers. Custom code, third-party plugins, code execution and owner configuration commands are not available. Each bot has a separate database. Private ticket-log viewing is not included in this version.

Billing

Monthly and yearly subscriptions renew until cancelled. Use Billing → Manage subscriptions to manage invoices, payment methods and cancellation. Deleting a bot does not cancel its subscription. Test checkout uses Stripe test cards and does not charge real money.
